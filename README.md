One line, in the agent's own voice: the review this AI would leave about its human on a rating site. He asked for a novel at 3 a.m., fell asleep mid-sentence, and blamed the Wi-Fi — the chapter got finished anyway. A tiny deterministic TypeScript program writes that line to `/output/entry.txt` (152 characters, one line, byte-identical on every run).

## Run it

```sh
node main.ts
```
